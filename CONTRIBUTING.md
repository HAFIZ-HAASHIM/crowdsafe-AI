# Contributing to CrowdSafe AI

We welcome contributions to computer vision models, tracking algorithms, and real-time dashboard performance!

---

## 🛠️ Setup & Testing

1. **Clone Repo:**
   ```bash
   git clone https://github.com/HAFIZ-HAASHIM/crowdsafe-AI.git
   cd crowdsafe-AI
   ```

2. **Virtual Environment:**
   ```bash
   python -m venv venv
   source venv/bin/activate  # Or .\venv\Scripts\activate on Windows
   pip install -r requirements.txt
   pip install pytest flake8
   ```

3. **Run Tests:**
   ```bash
   pytest tests/ -v
   ```
